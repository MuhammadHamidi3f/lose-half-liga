LOSE HALF LEAGUE — SEASON 02

Website statis untuk GitHub Pages.

CARA PAKAI:
1. Ekstrak ZIP ini.
2. Upload seluruh isi folder (index.html, style.css, app.js, assets/) ke root repository GitHub.
3. Buka Settings > Pages. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
4. Tunggu GitHub Pages selesai deploy.

FITUR:
- Beranda liga dan ringkasan kompetisi.
- Daftar 10 klub dan pencarian tim.
- Profil klub berisi logo, manager, dan gambar squad.
- Jadwal Matchday 10 sampai 18 berdasarkan file asli panitia.
- Preview gambar roster/jadwal dengan lightbox.
- Mode gelap/terang dan layout responsif.

CATATAN DATA:
Hasil pertandingan dan klasemen belum ditampilkan karena belum tersedia. Jadwal dipasang sebagai gambar sumber agar nama fixture tidak salah salin. Nama tim/manager di kartu profil mengikuti nama file aset yang diberikan.
